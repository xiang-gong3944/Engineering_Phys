# 東大物工 院試 解答集

[東京大学大学院 工学系研究科 物理工学専攻](https://www.phys.t.u-tokyo.ac.jp/) の大学院入試（物理）の問題と解答案をまとめているリポジトリです。

## ディレクトリ構造

```
Engineering_Phys/
├── {year}/
│   ├── {year}ap_exam.pdf       # 院試問題PDF
│   ├── {year}mathJ.pdf         # 数学問題PDF（年度による）
│   ├── ap_{year}.tex           # LaTeX解答ソース
│   ├── out/
│   │   └── ap_{year}.pdf       # 解答まとめPDF
│   └── content/
│       └── out/
│           ├── Phys01.pdf      # 物理解答（問題ごと）
│           ├── Phys02.pdf
│           └── MathNN.pdf      # 数学解答（問題ごと）
└── README.md
```
